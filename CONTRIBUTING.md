# Contributing to Universal Video Downloader (UVD)

Thank you for your interest in contributing to **Universal Video Downloader**! 🚀

We welcome contributions of all kinds: bug fixes, new features, UI enhancements, documentation improvements, and platform extractor updates.

---

## 🛠️ How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/your-username/universal-video-downloader.git
   cd universal-video-downloader
   ```
3. **Create a new branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Set up your environment**:
   ```bash
   pip install -r requirements.txt
   ```
5. **Make your changes** and test thoroughly:
   ```bash
   python app.py
   ```
6. **Commit your changes**:
   ```bash
   git commit -m "feat: add support for new platform format"
   ```
7. **Push to your branch**:
   ```bash
   git push origin feature/my-new-feature
   ```
8. **Open a Pull Request** describing your changes in detail.

---

## 📌 Guidelines

- Keep the UI **minimalist, clean, and terminal-styled** (dark mode, high contrast, no visual clutter).
- Ensure any added external dependencies are documented in `requirements.txt`.
- Do not commit personal credentials, API keys, or binary media files.
